# Roda Reinventada

Além dos dois eixos principais, analise se o código implementa manualmente algo que a própria tecnologia, linguagem, biblioteca ou framework já oferece de forma nativa ou mais simples.

Procure especialmente por:

- Funções nativas da linguagem ignoradas.
- Helpers do framework que substituiriam lógica manual.
- APIs padrão da biblioteca que tornam código customizado desnecessário.
- Coleções, pipelines, validadores, formatadores, normalizadores ou utilitários oficiais que substituiriam loops e condicionais manuais.
- Abstrações caseiras para algo que já existe de forma estável no stack usado.

Inclua esses achados no relatório final sob o título `## Roda Reinventada`.

Sempre valide com documentação atualizada via `context7` antes de afirmar que a tecnologia já oferece uma alternativa nativa ou mais simples.
