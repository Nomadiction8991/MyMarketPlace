# Por que Dois Eixos

Uma alteração pode passar em um eixo e falhar no outro:

- Código que segue todos os padrões mas implementa a coisa errada → **Padrões ok, Especificação falhou.**
- Código que faz exatamente o que a issue pediu mas quebra as convenções do projeto → **Especificação ok, Padrões falhou.**

Reportá-los separadamente impede que um eixo mascare o outro.
